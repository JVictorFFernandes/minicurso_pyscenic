# Minicurso pySCENIC - Resultados

Arquivos e dados gerados durante o minicurso prático de análise de redes de regulação gênica com **pySCENIC**.

## Arquivos no repositório

| Arquivo | Descrição |
| :--- | :--- |
| `adjacencias.tsv` | Tabela de coexpressão e adjacências calculadas entre fatores de transcrição e genes-alvo. |
| `regulons.csv` | Regulons identificados após a filtragem por enriquecimento de motivos de ligação (cisTarget). |
| `auc.csv` | Matriz de escores AUC da atividade dos regulons em cada célula/amostra. |
| `auc_binarizado.csv` | Matriz AUC binarizada com base nos limiares de atividade. |
| `rss.csv` | Regulon Specificity Score (RSS) por tipo celular. |
| `cytoscape_arestas.tsv` | Arestas para visualização da rede no Cytoscape. |
| `cytoscape_nos.tsv` | Nós/atributos dos fatores e alvos para Cytoscape. |
| `pbmc10k_contagens_filtradas.loom` | Matriz de contagens filtrada em formato Loom (PBMC 10k). |
